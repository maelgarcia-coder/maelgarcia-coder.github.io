Importante: Aprender requiere constancia. Es útil resaltar los conceptos clave, revisar fragmentos de código y leer avisos en letra pequeña.

En DAM, aprendemos distintos lenguajes de programación como:

  • Java
  • Kotlin
  • SQL
  • HTML

Una ver realizada una tarea, se debe guardar el proyecto en GitHub. Para ellos, hay que seguir estos pasos:

  1. Ejecutar git add . para añadir los cambios al stage.
  2. Ejecutar git commit -m "mensaje" para guardar los cambios localmente.
  3. Ejecutar git push para subir los cambios al repositorio remoto.

Definición de términos

HTML
Lenguaje de marcado estándar para la creación de páginas web.
CSS
Lenguaje utilizado para definir la presentación y el estilo de un documento estructurado.
DOM
Estructura en forma de árbol que representa todos los elementos de una página web para poder interactuar con ellos.
